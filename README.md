# Architecture of Care — Atelier Edition

A 49-slide interactive architectural study of **Tata Medical Center** and **MVR Cancer Centre**.

**Presentation by:** Zhyar Peshraw - Bria - Yasr - Akam - Soma - Nma - Layad

## Play offline

1. Extract the ZIP completely.
2. Open `architecture-of-care/index.html` in Chrome, Edge, Firefox or Safari.
3. Select **Full screen** or press **F**. Use **← / →** to move through the slides.

Keep the files and folders together. The presentation includes its images, drawings, font, JavaScript and styles. It does not need installation, a build command, a local server or an internet connection. The optional external references in **Sources** require internet access.

## Present the analysis

| Control | Action |
| --- | --- |
| Chapter tabs | Jump to the introduction, Tata, MVR or synthesis |
| Explore / O | Search all 49 slides and filter by chapter |
| B / Next observation | Reveal one plan callout at a time |
| Play observations | Reveal the next callout every 3.8 seconds |
| Show all | Restore the complete annotated plan |
| Route category buttons | Isolate patient, staff, emergency, service or hallway hierarchy |
| Animate journeys / J | Cycle the available route categories |
| D / Focus | Maximize the presentation; move to the screen edge to reveal controls |
| L / Laser | Toggle the presentation pointer |
| Inspect original / Enlarge | Open a drawing or analytical figure |
| Wheel / drag | Zoom / pan in drawing inspectors |
| Auto play | Advance every 20 seconds; pauses while a dialog is open |
| M / Motion | Toggle visual animations and stop active analytical cycles |
| N / R / G | Presenter notes / source register / image gallery |
| ? | Open the presenter guide |
| Esc | Close a dialog |

Color legends are attached to all 15 source plans, including their enlarged inspectors. Colored OT route samples appear on slide 37. Click a department in a floor-plan legend to inspect that named source area. The Tata basement key describes the evacuation drawing colors; red is not assigned to a clinical department.

The system’s reduced-motion preference is respected on first load. No arrowheads are shown on the functional relationship diagram on slide 2. The earlier typefaces are restored: P052 for display titles and Nimbus Sans for labels and body text. Both are embedded locally.

## Publish on GitHub

Read **[GITHUB-UPLOAD.md](GITHUB-UPLOAD.md)**. Upload the **extracted website files**, with `index.html` at the repository root. The ZIP is the download package; GitHub Pages serves the extracted site.

All website files are below 2 MiB. Upload the root files, then each asset folder in its own batch to stay below GitHub’s 100-file browser-upload limit.

## Edit the presentation

- `presentation.js` contains the source data, slide content and interactions. Section comments retain the original source-file names. The final `Architecture of Care` section contains the revised titles and studio controls.
- `presentation.css` contains the original source-drawing styles and the studio foundation.
- `atelier.js` / `atelier.css` contain the latest source-specific legends, typography, image correction and motion design.
- `plans/`, `source-sheets/`, `team-analysis/` and `details/` contain the drawing assets.
- `photos/` contains the photographs and renderings; `fonts/` contains the earlier bundled typefaces.
- `SOURCE-AUDIT.txt` records the source-reading decisions and original analysis method.
- `PACKAGE-REPORT.txt` records package size and validation results.

Plan and source-sheet pixel dimensions are retained. Image compression is high-quality WebP; large photographs are limited to 1800 pixels on their longest edge. Duplicate image copies are shared. The vector coordinates and the approved analysis are unchanged.
